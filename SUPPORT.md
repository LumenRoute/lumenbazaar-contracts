# Support

Use GitHub issues for reproducible contract, binding, deployment-script, and documentation defects.
Include the contract, function, network, public transaction hash when available, expected result,
actual result, and safe reproduction steps.

Never post seed phrases, secret keys, signing files, or private wallet material. Report vulnerabilities
through the private process in `SECURITY.md`.

The published contracts are testnet software. They have no mainnet, asset-value, or availability
guarantee.
